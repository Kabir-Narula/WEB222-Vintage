# RB Music — Vintage Web Capstone

**WEB222 capstone** — Seneca College, 2023.

Vintage-styled music artist page featuring Keshi, Niki, and The 1975 — dynamic menus, interactive song cards, and nostalgic CSS design.

## Highlights

- Artist navigation built from structured data arrays
- Trading-card style song displays with hover animations
- Muted earthy palette and typewriter-inspired typography

## Stack

HTML · CSS · JavaScript

## Run locally

Open `index.html` or serve the project folder statically.
